# Project Euler Solutions

Personal collection of solutions for [Project Euler](https://projecteuler.net/) mathematical and computational programming challenges.

---

## Summary & Progress

- **Language:** Python 3.x
- **Target:** Solve problems with efficient algorithms (execution time < 1s per problem)

---

## Repository Structure

```text
project-euler/
├── solutions/                  # Individual problem solutions (e.g. q001_multiples_of_3_and_5.py)
└── tests/                      # Unit tests for each solution (e.g. test_q001.py)
```
